# notebk — Stage 6

## الهوية البصرية + الشعار + تعديل وحذف السجلات

تم تنفيذ المرحلة السادسة فوق Stage 5 بدون حذف قاعدة البيانات أو السجلات.

### الشعار
- استخدام الشعار المرفق كهوية موحدة للتطبيق.
- تحديث أيقونة التطبيق وround icon.
- شاشة بداية متحركة بالشعار لمدة قصيرة عند التشغيل.
- ظهور الشعار في الشريط العلوي للشاشات الرئيسية: الدفتر، السجل الفردي، الإحصائيات، التقارير، والإعدادات.
- تضمين الشعار في رأس كل صفحة من تقرير PDF، مع تذييل يحمل اسم التطبيق.
- الطباعة والمشاركة تستخدمان نفس PDF الموشح بالشعار.

### السجلات
- تعديل السجل مع الحفاظ على `id` والتاريخ الأصلي.
- إعادة حساب الرصيد بعد التعديل.
- حذف السجل مع تأكيد من المستخدم.
- إعادة حساب الرصيد بعد الحذف.
- تعديل الإنتاج يعيد حساب المبلغ تلقائيًا من الكمية × سعر القطعة.
- تعديل المصروف يسمح بإدخال المبلغ يدويًا.

### الحفاظ على البيانات
- SQLite الحالية محفوظة.
- لا يوجد حذف جماعي أو إعادة إنشاء تلقائية لقاعدة البيانات.
- النسخ الاحتياطي واستعادة البيانات من Stage 5 محفوظان.
