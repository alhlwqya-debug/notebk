# Stage 9 — Home First / No Automatic Popups

- The application now opens on the main Home Dashboard after the splash screen.
- No shop-creation dialog is opened automatically on first launch.
- The user profile dialog is no longer opened automatically when the profile is empty.
- The Help/Onboarding dialog is no longer opened automatically.
- If there are no shops yet, the Home Dashboard shows the normal empty-state with an explicit “إضافة محل” action.
- Adding a shop remains available from the Home Dashboard and the side drawer.
- Existing shop/month/work data is preserved.
- Direct table registration and the daily-work button remain unchanged.
